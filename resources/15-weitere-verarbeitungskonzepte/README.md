# UE 15 – Weitere Verarbeitungskonzepte

## Lernabsicht

Window Functions, Caching und Parquet-Ausgabe.

## Beispiele

- `window_cache_parquet.py`

Die Programme verwenden jeweils eine `main()`-Funktion und sind eigenständig startbar. Sie dienen als Demonstrationen; Übungen und Handout werden separat erstellt.

## Ausführung

Im Dev Container vom Repository-Wurzelverzeichnis aus:

```bash
python resources/15-weitere-verarbeitungskonzepte/src/window_cache_parquet.py
```
