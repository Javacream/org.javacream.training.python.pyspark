# UE 10 – Daten einlesen und untersuchen

## Lernabsicht

CSV/JSON, Schema-Inferenz, explizite Schemas, show und printSchema.

## Beispiele

- `read_csv_json.py`

Die Programme verwenden jeweils eine `main()`-Funktion und sind eigenständig startbar. Sie dienen als Demonstrationen; Übungen und Handout werden separat erstellt.

## Ausführung

Im Dev Container vom Repository-Wurzelverzeichnis aus:

```bash
python resources/10-daten-einlesen-und-untersuchen/src/read_csv_json.py
```
