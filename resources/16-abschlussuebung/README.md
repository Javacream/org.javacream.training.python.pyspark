# UE 16 – Abschlussübung

## Lernabsicht

Zusammenhängende ETL-Pipeline mit mehreren Quellen und Ergebnisdateien.

## Beispiele

- `etl_pipeline.py`

Die Programme verwenden jeweils eine `main()`-Funktion und sind eigenständig startbar. Sie dienen als Demonstrationen; Übungen und Handout werden separat erstellt.

## Ausführung

Im Dev Container vom Repository-Wurzelverzeichnis aus:

```bash
python resources/16-abschlussuebung/src/etl_pipeline.py
```

**Hinweis:** Die Beispieldaten und Ausgabedateien werden in einem temporären Verzeichnis erzeugt und nach Programmende gelöscht.
